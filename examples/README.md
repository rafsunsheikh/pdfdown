# Examples

Each folder holds an open-access paper, its Markdown made by `pdfdown --batch` with no hand edits, and
the figures, tables and equations pdfdown cropped from it. Open a `.md` file on GitHub to see it rendered.

| Folder | Paper | Licence |
| --- | --- | --- |
| `imaginary-magnetic-fields/` | S. Alminas, D. Burba and G. Juzeliūnas, "Imaginary magnetic fields for ultracold atoms", [arXiv:2610.06793](https://arxiv.org/abs/2610.06793) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| `llama/` | H. Touvron et al., "LLaMA: Open and Efficient Foundation Language Models", [arXiv:2302.13971](https://arxiv.org/abs/2302.13971) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |
| `dpo/` | R. Rafailov et al., "Direct Preference Optimization: Your Language Model is Secretly a Reward Model", [arXiv:2305.18290](https://arxiv.org/abs/2305.18290) | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) |

The PDFs are the authors' arXiv versions, unchanged. The Markdown files and images are adaptations made
by pdfdown: the text was converted to Markdown, and figures, tables and equations were cropped from the
pages. They are shared under the same licence as the papers. The papers' authors have not reviewed or
endorsed pdfdown.
